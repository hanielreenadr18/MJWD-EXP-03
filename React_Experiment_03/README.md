## Run the application
1. Open this experiment folder in VS Code.
2. Open the terminal in this folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the Vite development server:
   ```bash
   npm run dev
   ```
5. Open the localhost URL shown in the terminal.
